# Road-Accident-Dashboards
This project analyzes road accident data using Microsoft Excel to identify trends, patterns, and key insights related to traffic accidents. The dataset used in this project was downloaded from Kaggle and processed using Excel features such as Pivot Tables, Charts, Dashboards, and Data Visualization techniques.

Features
Data cleaning and preprocessing in Excel
Interactive dashboard with charts and graphs
Analysis of accident severity, location, and time
Trend analysis to identify accident patterns
Easy-to-understand visual reports
Tools Used
Microsoft Excel
Kaggle Road Accident Dataset
Dataset

The dataset is sourced from Kaggle and is used for educational and analytical purposes.

Objective

The main goal of this project is to transform raw road accident data into meaningful insights that can help understand accident trends and support data-driven decision-making.
